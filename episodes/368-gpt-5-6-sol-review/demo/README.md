# SALTWIND · Regatta 01

一款基于 Three.js 的低多边形帆船竞速小游戏。穿过 7 道航门、收集风之碎片，并通过调帆与蓄力阵风刷新最快成绩。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- `A / D` 或方向键：左转 / 右转
- `W`：放松帆
- `S`：收紧帆
- 按住 `Space`：蓄力；松开：释放阵风冲刺
- `P / Esc`：暂停或继续
- `R`：重新开始
- `M`：静音或恢复声音

首次点击“开始比赛”后，浏览器才会解锁程序化风声、浪声和比赛音效。
