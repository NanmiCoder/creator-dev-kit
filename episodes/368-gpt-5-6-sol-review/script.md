# GPT-5.6 正式发布：OpenAI 卖的已经不是模型了

> 成片时长：约 7-8 分钟。
> 结构：发布事件 -> 人话翻译 -> 数据反查 -> 主观判断 -> 使用建议。

## 0 · 开场：这次发布的不是一个模型

OpenAI 正式发布 GPT-5.6 了。

先说结论。

这次真正值得看的，不是 Sol 又拿了几个第一，而是 OpenAI 开始把 AI 做成一套可以按预算、按时间、按任务难度扩容的生产系统。

说句人话：以前我们只是在选模型。现在你还要决定雇哪个档位、让它想多久，以及要不要再叫几个 Agent 一起干。

官方给这篇文章起的标题是“随你的雄心扩展的前沿智能”。

翻译一下就是：任务越难，它就继续加时间、加 Token、加 Agent。当然了，账单也会跟着你的雄心一起扩展。

## 1 · 三档模型，其实是一次产品线重构

这次 OpenAI 一口气发了三个档位。

Sol 是旗舰，Terra 是日常均衡款，Luna 最快也最便宜。

有个细节很重要：官方说 `5.6` 代表模型代际，Sol、Terra、Luna 则是可以按照各自节奏单独升级的长期能力档位。

所以这不是临时换了三个名字，而是在重做产品线。

硬骨头交给 Sol，日常工作交给 Terra，需要批量跑的任务交给 Luna。

API 每百万 Token 的输入和输出价格分别是：Sol 5 美元和 30 美元，Terra 2.5 美元和 15 美元，Luna 1 美元和 6 美元。

Sol 的输出价格正好是 Luna 的五倍。以后什么任务都无脑上旗舰，不一定叫追求效果，也可能只是钱比较多。

## 2 · 它没全面碾压，真正想赢的是单位美元产出

整篇文章反复强调的，其实不是“我们最聪明”，而是让每一个 Token 产出更多有用的工作。

正文里写，覆盖 55 个专业领域的 Agents' Last Exam，Sol 拿到 53.6 分，比 Claude Fable 5 高 13.1 分。即使只开中等推理，仍然领先 11.4 分，官方估算成本大约只有对方四分之一。

Terra 和 Luna 更夸张，官方称它们能用大约十六分之一的预估成本超过 Fable 5。

好家伙，十六分之一确实很猛。

但先别急着宣布全面碾压。

OpenAI 自己放出的完整表格里，SWE-Bench Pro 上 Sol 是 64.6%，Fable 5 是 80%；FrontierMath Tier 4，Sol 是 65.9%，反而低于 GPT-5.5 的 72.5%。

而且正文写 Agents' Last Exam 是 53.6，后面的汇总表里 Sol 又是 52.7。很可能运行设置不同，但页面并没有把口径讲得特别明白。

所以更准确的判断是：GPT-5.6 没有证明自己在所有能力上全面碾压，但它把“同样一美元能完成多少工作”放到了发布文章的正中央。

这些成本和延迟还属于官方估算。卖家算出来的账可以参考，不能直接当成你的信用卡账单。

## 3 · max、ultra 和真正的大升级

然后是两个新的算力档位。

`max` 是让一个模型花更多时间推理、检查和返工。说白了，就是让一个人多加一会儿班。

`ultra` 则默认拉起四个 Agent 并行工作，部分评测甚至展示了 16 Agent 配置。

但官方写得很清楚：ultra 是用更高 Token 消耗，换更强结果和更短完成时间。

所以它卖的不是免费智力，而是并行算力。墙上的时间可能变短，账单不一定变小。

这次还有一个更重要的功能，叫 Programmatic Tool Calling。

以前 Agent 每拿到一大坨工具结果，往往都要重新塞回模型，读完再决定下一步。数据一多，Token 多、往返多、上下文也越来越脏。

GPT-5.6 现在可以在内存里自己写并运行轻量程序，去协调工具、处理数据、监控进度，只把真正重要的结果留下来。

人话翻译：以前每个工具干完活，都要把原始材料抱回来开会；现在 Agent 可以自己写个小程序，先把废话删掉，再带着结论回来。

OpenAI 称这样能减少 Token、模型往返和人工指导，并且兼容 Zero Data Retention。实际能省多少，文章没有给统一数字。

但方向很清楚：以前需要开发者手写的 Agent 编排，正在被 OpenAI 直接收进平台能力里。

## 4 · 它想交付的不是答案，而是整件工作

官方希望 GPT-5.6 能把文档、Slack、Notion、Microsoft 365 和 Google Drive 里又乱又碎的上下文，整理成可以直接分享的完整成果。

发布页突出 BrowseComp 的 92.2%，但仔细看表格，这个成绩对应的是 Sol Ultra，普通 Sol 是 90.4%。差距没有大到离谱，使用条件还是要讲清楚。

在电脑操作评测 OSWorld 2.0 上，Sol 是 62.6%，官方称它比 Opus 4.8 少用了 85% 的输出 Token。

所以 OpenAI 想表达的不是“我又更会回答问题了”，而是“你把一堆零散材料扔给我，我可以跨工具把整件事做完”。

## 5 · 文章后半段，藏着真正的大新闻

我认为整篇文章最值得讨论的一节，标题叫 `GPT-5.6 accelerates OpenAI`，也就是 GPT-5.6 正在加速 OpenAI 自己。

OpenAI 说，研究人员已经用它诊断失败、优化训练系统、运行实验和解释结果。

内测期间，每位活跃研究员每天使用的输出 Token，超过 GPT-5.5 历史最高水平的两倍。

过去六个月，OpenAI 内部用于代码推理的研究算力占比增长了 100 倍，Agent Token 使用量增长约 22 倍。内部 RSI 评测里，Sol 又比 GPT-5.5 高了 16.2 分。

看到这里先别急着喊“AI 已经自己造 AI 了”。

官方自己也提醒，这些使用量数据不能直接代表研究进展。100 倍算力占比，不等于研发效率提高 100 倍。

但有一件事已经很清楚：模型帮助研究人员开发下一代模型的反馈循环，正在明显加速。

今天某张榜单高两分、低三分，过几个月可能没人记得；如果 AI 真能持续缩短下一代 AI 的研发周期，这个影响会大得多。

## 6 · 能力越强，权限也开始分层

官方说 GPT-5.6 在生物和网络安全方面都更强，但还没有跨过他们定义的 Critical 门槛。

同时，Sol 的网络安全保护会比以前拦截大约十倍的潜在有害活动。发布前，OpenAI 还投入约 70 万个 A100e GPU 小时做自动化黑盒红队。

系统这次还加入 reasoning monitor，根据上下文判断请求有没有潜在危害。更敏感的能力则放进 Trusted Access，要求用户验证身份和使用环境。

也就是说，以后最强能力的分层可能不只看你付了多少钱，还要看你是谁、准备用在哪里。

更严格的保护也会误伤正常工作。这一点官方自己承认了，所以 ChatGPT 和 Codex 会提供切换到低能力模型重试的选项。

## 7 · 总结：模型正在变成算力调度系统

最后总结。

GPT-5.6 已经开始在 ChatGPT、Codex 和 API 全球推送，官方计划在 24 小时内逐步开放。Free 和 Go 用户主要使用 Terra；在 ChatGPT Work 和 Codex 里，Plus 及以上用户可以选择不同档位，Codex 的 Plus 及以上套餐也能使用 ultra。

GPT-5.6 不是一张所有榜单全部第一的成绩单。

它真正的变化，是 OpenAI 把模型档位、推理时间、并行 Agent 数量，以及基于身份和风险的能力权限，放进了同一套产品。

以前我们买的是一个模型。现在更像是在买一套可以按任务价值动态扩容的 AI 劳动力。

日常任务，Terra 和 Luna 可能已经够了。真正复杂、时间敏感，而且结果价值很高的任务，才值得上 Sol、max，甚至 ultra。

所以我的判断是：GPT-5.6 未必在每一项能力上都封神，但 OpenAI 确实把竞争从“谁的单体智商最高”，推进到了“谁能更便宜、更快地组织一群 Agent 把工作做完”。

如果你觉得这种新模型发布后，直接拆官方话术、算成本、讲影响的内容更有用，评论区告诉我。
