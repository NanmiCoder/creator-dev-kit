## 画面信息池

- 项目量级：13,000+ Star、8,000+ Fork、110,000+ 安装包下载
- 核心评论截图：`presentation/public/media/comment-malware-claim.png`
- 误报链路：Windows 未签名、截图、鼠标点击、键盘输入、杀软启发式标红
- 工程风险示例：NPM 依赖、供应链、发布链路、沙箱边界
- 上游命令链：模型返回 → Agent 接收 → bash 执行 → 联网下载 → 本机运行
- Skill 风险面：读写文件、环境变量与 Key、运行命令、访问网络
- 结论：不要只问“工具有没有毒”，还要问模型、Provider、Skill 和命令到底来自谁
