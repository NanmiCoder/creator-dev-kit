# DeepSeek V4 Flash Vision × PerceptionBench 评测报告

评测日期：2026-08-21

## 结论

`deepseek-v4-flash-vision-exp` 在 PerceptionBench 3,000 道题上得分 **34.93%**（**1048 / 3000**）。如将这一结果插入仓库 README 的 16 个模型榜单，将位于 GLM-5V-Turbo（39.6）与 Minimax-M3（33.1）之间，约为 **第 15 / 17**。

> 可比性提醒：README 的分数使用 `gpt-oss-120b` 做裁判，而 DeepSeek API 不提供该模型。本次保持了原仓库的题目、作答提示词、裁判提示词和 0/1 计分方法，但裁判模型改为了该端点内最强的 `deepseek-v4-pro`。因此“第 15 / 17”是近似对比，不是 PerceptionBench 官方同口径排名。
