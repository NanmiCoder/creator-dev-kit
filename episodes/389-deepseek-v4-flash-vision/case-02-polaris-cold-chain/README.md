## 实现说明（POLARIS · 冷链运控中心）

Case 02 实时运营后台 — 长三角冷链运输实时运控后台。React + TypeScript + Vite，无地图 API、无 UI 组件库；地图为自绘 SVG 路网，动画基于 CSS transform/opacity 与隔离的 rAF 循环。

## 运行

```bash
cd app
npm ci
npm run dev        # http://localhost:5199 （--port 5199 --strictPort 已内置避免端口冲突）
npm run build      # tsc -b && vite build
npm run preview
```

## 功能地图

- **地图**：自绘长三角路网（上海/苏州/杭州/宁波/嘉兴/无锡/湖州/绍兴等 12 节点 + G2/G42/G60/G15/G92 等线路 + 长江口/杭州湾/太湖水域），12 辆代表车辆沿路线巡游（rAF 直写 DOM，不触发 React 重渲染）；悬停玻璃浮层（车牌/司机/货物/温度/ETA）；选中后路线琥珀高亮、其余降噪并轻度平移聚焦。
- **顶部状态条**：班次、实时时钟（1s 隔离刷新）、在线车辆 184/191、动态岛（正常 / 风险 / 处理中 三态形变，处理完成 3s 后自动回落）。
- **KPI 区**：准点率（仪表弧）+ 运输中 + 温控风险（联动计数）+ 今日里程（sparkline），非对称布局，无重复卡片。
- **事件流**：10 条真实细节事件，按温控/延误/装卸/信息筛选；点击异常 → 地图聚焦车辆 + 打开详情。
- **车队表格**：25 辆，搜索（车牌/司机/货物/路线/订单）、状态筛选、五列排序、折叠、CSV 导出；行点击联动地图与抽屉。
- **车辆抽屉**：温度折线图（目标线 + 极值标注）、行程进度步骤、货物批次、司机电话（tel:）、关联事件、`标记已处理`（事件状态 / KPI / 动态岛同步）。
- **快捷指令**：`/` 或 `Cmd/Ctrl + K` 打开；支持车辆/订单搜索与指令（只看温控风险、重置视图、导出 CSV、夜间模式等），↑↓/Enter/Esc 键盘导航。
- **Demo State**：正常 / 加载中（骨架屏）/ 空数据（空状态）/ 接口错误（内联错误 + 重试）。
- **响应式**：1440 桌面（左导航 + 悬浮面板）；平板/手机转为「地图 + 底部抽屉」——事件流变为底部弹层（右下 LIVE 按钮），抽屉全宽。
