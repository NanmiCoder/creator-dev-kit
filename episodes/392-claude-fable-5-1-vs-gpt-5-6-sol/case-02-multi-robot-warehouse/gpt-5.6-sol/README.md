# 航点调度 · 多机器人仓库仿真系统

一个服务端权威控制的确定性仓库调度器。系统包含 8 台机器人、32 个货架库位、4 个工作站与 5 条单格宽瓶颈通道。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

开发界面默认为 `http://localhost:5173`，API 服务为 `http://localhost:3001`。

## 生产构建

```bash
npm run build
PORT=4012 npm start
```

然后打开 [http://localhost:4012](http://localhost:4012)。

## 验证

```bash
npm run typecheck
npm test
npm run build
```

测试覆盖地图数量约束、多任务连续运行时的顶点碰撞/交换碰撞不变式、动态封锁后的立即重规划，以及持久化恢复。

## 调度机制

- 后端使用带等待动作的时空 A* 规划路径。
- 顶点预留防止同时占用，边预留防止相互交换位置。
- 单格瓶颈通道使用方向锁，防止狭窄通道中的永久对头死锁。
- 优先级随等待时间老化，长时间排队的任务会逐步提高有效优先级。
- SSE 连接首先发送完整快照，之后只应用序列号更新的状态。
- 当前运行会持久化到 `data/state.json`，刷新页面或重启服务后可继续观察。
