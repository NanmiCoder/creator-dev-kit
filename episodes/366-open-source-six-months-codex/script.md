## 01 开场：免费结果 + 反常识悬念

我刚刚一分钱没花，拿到了 OpenAI 给我送的 6 个月免费 Codex 套餐，是 20X 这个档位的，就是 200 刀一个月。

直接送了 6 个月，这个 OpenAI 真的真的太大方了，大概价值 8,000 多块钱。

这不是抽奖，也不是灰产羊毛。它是官方给开源项目维护者的一个免费福利。

但这一期的话，我不是想给大家炫耀这个东西。真正有意思的是，我之前有 50K star 的开源项目 MediaCrawler，申请过很多次都没有通过。

反而是这一次的一个新的开源项目 cc-haha，它有 10K star，反而给我过了。

所以它审核到底在看什么？普通开发者现在从 0 去做开源项目还有没有一个机会？

这期视频我就会把我的一个申请的经验，还有我对开源项目的理解，直接毫无保留地分享给你。

## 02 官方入口：这个福利到底是什么

OK，下面我们先看一下这个官方的申请表单页面。官方其实写得非常清楚，如果你是一个开源项目的维护者，你是可以去申请 API 的调用，或者你申请这个 6 个月的 ChatGPT Pro 这个套餐。

我这次拿到的话，是 6 个月的 ChatGPT Pro with Codex，也就是我们通常所说的 Codex 那个 20X 套餐。

那对于我这种平时大量使用 Codex 去做开源项目的人来说，这个是真的非常香。因为我之前每个月 AI 订阅的费用经常两三千块人民币，说没就没了。

而且很多消耗不是拿来玩的，是真实拿去修 issue、改 bug、发版本、做一些自媒体素材。

所以这次对我来说，不简简单单只是省钱，更像是我做开源项目这么久以来，它给我了一个非常好的反馈信号。

## 03 申请判断：不一定只看 Star

但我这里先说一个反常识的点。我感觉它这个审核不一定只看 star。因为我刚刚那个 50K star 也没通过。

下面说一下我的个人判断，不是官方的标准。首先它会看你是不是这个核心项目的维护者，还有这个项目最近维护得活不活跃，它的 issue、release 有没有持续在发生，还有就是这个项目是不是真的给用户带来了价值。

翻译成人话就是：我感觉如果纯包装成一个 GitHub 项目去申请的话，它审核通过的概率不是很高。我们得证明这个项目真的有人在用，真的在维护。

那怎么证明？就是你的 commit、你的 release 下载、还有你的一些贡献的人，这些都可以去证明。

## 04 申请方法

那具体怎么申请？其实这个流程并不复杂，就是填一个我们刚刚看到这个表单。

你完全可以把这个表单链接给你一个你正在用的 agent，然后让它根据你的 GitHub 主页，去找一个你最可能申请的项目，根据每个项目的特点去填写。

那我自己也没有人工去填这个表单。我是把我的 GitHub 主页丢给了 Codex，让 Codex 使用浏览器插件，帮我们去自动把这个表单填写了。我填写了很多次。

这里有一个需要注意的点，就是你平时 commit 的邮箱，最好是保持跟你的 GitHub 主页的邮箱设置一致。还有就是你需要把 GitHub 的邮箱设置为公开。最重要的一点，你需要把你 GPT 的账号邮箱保证跟你 GitHub 的一致，这样子大大的能够提高整个申请的通过率。

## 05 从 0 开始：没有项目也别硬造

那很多人可能就会说，我现在没有开源项目，是不是就没有机会？我的建议就是，你不要为了一个福利去硬造这种开源项目。

你可以先做一个自己真正需要，并且别人也可能需要的小工具。现在 AI 写代码已经不是最难的事了，非常非常简单。

真正难的是三件事情：第一，你能不能找到一个真实的问题；第二，你能不能把它做成别人能用的东西；第三，你能不能持续去维护。

比如现在很适合普通开发者做的方向，不一定是大而全的软件。你可以做一个小的工具，甚至是一个 skill。大家都知道有很多 skills 非常非常火，它的 star 也非常高。其实简单来说，它就是一段提示词。

甚至你可以把你的一些脚本、一套工作流，甚至是一段提示词，都可以把它放上去。只要这个东西真的能帮别人省时间，它就有开源价值。

## 06 开源飞轮：用户、issue、版本、素材

那我自己刚开始做 cc-haha 这个开源项目的时候，也不是一开始就想做什么大的项目。

就想着 Claude Code 源代码泄露的时候，肯定有人会有需求，想要在自己的本地尝试把这个泄露源代码跑起来。

于是我当时就把这个泄露源代码，让 AI 在本地帮我去补一些缺的代码，然后我自己本地再调试调试，最后它就可以跑起来了，然后就把它开源写出来了。

最后我在自媒体上发声了，把它开源出来之后，第一批用户就进来了。他们会去提需求，会去反馈 bug。那我后面就修，然后加功能、发版本。

有了新功能，我又可以继续去发视频。视频又带来了新的用户，而用户又带来了新的 issue，也许又推动了新的版本，最后又变成新的需求。

这个飞轮一旦转起来，项目增长真的非常非常快。

## 07 开源回报 + 总结

所以我现在越来越觉得，做开源项目是一件复利很强的事情。

它前期可能不赚钱，甚至还挺累的，但是它会给你带来三种东西：认可、机会、素材。

最后总结一下。如果你想申请 Codex 给开源项目的福利，或者 Anthropic 也有这样的福利，先看三个问题。

第一，你是不是这个项目的 owner 或者核心维护者。第二，这个项目是不是有人在用，并且持续在维护。第三，你能不能让 AI 帮你说清楚 Codex 怎么帮你做开源项目维护。

这三点说清楚的话，你真的可以让你的 AI 帮你自动化去申请，定时比如隔个两天去申请一次。

说不清楚也没有关系，先不要着急去薅它这个福利，你可以先把自己的项目做实。

开源这件事情，短期看真的是免费打工；但长期看，它是真的在积累你的信用、你的作品、你的真实用户。

这次我拿这一个免费的 6 个月，就是一个很好的典型例子。
