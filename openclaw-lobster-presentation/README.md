# OpenClaw 龙虾玩法 - 演示幻灯片

「OpenClaw 龙虾玩法」视频配套演示站点，展示养龙虾的三个层次与实战工作流。

## 内容概要

- **L1 能用**：装好了不崩，能在手机 IM 上稳定对话
- **L2 有用**：它替你干活——主动抓话题、监控大V动态、早上提醒待办
- **L3 离不开**：它有你的记忆、偏好、工作流
- **四个量化指标**：判断龙虾养得好不好
- **实操演示**：3 个 Discord Bot + 十几个自定义 Skill

## 本地运行

```bash
npm install
npm run dev
```

## 技术栈

- React + Vite
- Framer Motion（动画）
- Tailwind CSS
- Lucide React（图标）
