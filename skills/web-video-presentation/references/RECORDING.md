# 录制与后期

三条路径，按手上有什么音频选：

| 场景 | 路径 |
|---|---|
| 真人口播 VO-First（主路径） | `?auto=1` 播整段原声、按绝对时间轴翻页 → 录屏即主轨，零对轨 |
| TTS 已合成 | `?auto=1` 每步播 mp3 自动推进 → 一镜到底 |
| 无音频 | Manual 手动点击推进 → 后期任意剪辑工具配音 |

## 模式速查

| URL / 按键 | 行为 |
|---|---|
| 直接打开 | Manual：点击 / ←→ 推进，不播音频 |
| `?audio=1` 或按 `M` 切换 | Audio：进 step 播该步音频，手动推进（预览用） |
| `?auto=1` | Auto：整段时间轴（VO-First）或逐段 mp3（TTS）自动播 + 自动翻页 |
| `?auto=1&part=<id>` | 只播 plan.md `parts` 里该区间（VO-First 补拍 / 分段录制） |
| `?mute=1` | **静音**播放 —— 音频照常解码、`currentTime` 照常推进、`ended` 照常触发，翻页行为与有声时逐帧一致，只是听不见。**给 agent 自动化验证用**（`?auto=1&mute=1`），起播蒙层会显示「静音验证」。**录制时必须去掉** |
| Auto 下首次 `Space` | 起播（浏览器要用户手势）。**只起播不翻页** —— 模板已守卫 |

## VO-First：录制 + 后期装配

**录制**：浏览器全屏开 `?auto=1`（多区间时 `?auto=1&part=a`）→ 开录 → 按 Space。
整段原声 seek 到区间起点连续播，画面跨过每个 step 的绝对起始秒自动翻页，
到区间 end 自动暂停、画面定住 —— 即可停录。

**为什么整段不切片**：切成 N 段 mp3 顺次播，段间有断点（听感割裂）、切割点不一定
在换气处、`ended → next → play` 每段几十 ms 延迟会累积漂移。整段 + 绝对时间戳 =
零割裂、零漂移、与真人头像 mp4 逐帧对齐。机制详见模板 `src/hooks/useTimelineAuto.ts` 注释。

**后期装配**：
- 主轨 = 录出的网页画面 + 完整原声，翻页已钉死 SRT 绝对时间
- 叠头像：口播视频抠像（如 Screen Studio）→ 圆形贴 `AVATAR_CORNER` 角。
  头像 mp4 的声音与网页音频同源 → **逐帧同步不用对轨**，成片用谁的声轨都行
- 整屏实测视频步的 ~0.5s 短闪点 = 剪辑切点，把实测录屏（各带原声）切进去
- **多区间补拍**：各 part 分别录（`?auto=1&part=a`、`?auto=1&part=b`…），后期按
  plan.md 各区间的**绝对起止秒**替换成片对应时段 —— 时间轴用的就是成片绝对秒，
  不用算偏移量，区间边界即切点

## TTS：Auto 一镜到底

前置：`public/audio/<id>/<N>.mp3` 全部就位（`npm run extract-narrations` →
`npm run synthesize-audio`，见 [`AUDIO.md`](AUDIO.md)）。

1. 浏览器全屏开 `?auto=1`，出现 "Press SPACE to start" 蒙层
2. 开录 → 按一次 Space → 逐步自动播 mp3 并推进 → 终态停住 → 停录，裁头尾即成品

> Auto 严格按音频结束推进（+200ms 缓冲），没有"等动画跑完"的兜底。看到动画被切 =
> 该步动画长于口播 → 调快动画 / 精简元素 / 拆 step（见 CRAFT.md ⑤）。

## 录制就绪硬化清单（开录前逐项过）

1. **回到起点**：游标存 localStorage。按 `Home`（Mac：`fn + ←`）或数字 `1` 回开头，
   肉眼确认画面在第一页；VO-First 分区间录时确认蒙层显示的起止秒是想录的区间
2. **无 chrome 无 letterbox**：浏览器全屏藏地址栏。黑边 = 窗口非 16:9，不是设计
   padding：16:9 外接屏全屏完美铺满；16:10 笔记本用 Screen Studio 框 16:9 或后期裁
3. **控件不入镜**：进度条 / 模式按钮悬停才出现 —— 开录后鼠标移到角落或移出屏幕别动
4. **Space 只起播不跳步**：模板守卫「`.auto-gate` 在屏时 Space 不翻页」，
   但仍要试录确认开场第一句在（丢 step 0 = 白录一整条）
5. **试录 10 秒**回放确认：① 第一句在 ② 无黑边裁歪 ③ 无按钮入镜 ④ 声画合拍。OK 再正式录
6. 记下整屏视频步闪点的大概时间，后期接实测视频
7. 一上来就 `git init`、每个满意版本 commit —— 别等做完才想起没仓库
