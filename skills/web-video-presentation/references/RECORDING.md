# 导出、录制与后期

成片优先用预览页右上角 **导出**。浏览器捕获当前标签页的舞台（合成器出图 + 硬件编码），叠上导入的原声，下载 MP4。耗时约等于片长，不是逐帧截 DOM。录屏软件只在捕获失败或旧浏览器时使用。

## 页面导出（主路径）

1. 打开预览，看完要导出的区间。点开预览不会无手势出声：有配音时先点蒙层或按 Space。
2. 点右上角 **导出**（始终可见，不靠悬停）。
3. 选 1K（1920×1080）、2K（2560×1440）或 4K（3840×2160）。多 part 时再选当前区间或全片。
4. 点确认后，Chrome 会弹出「分享标签页」——**必须选当前这个标签页**，不要选整个屏幕。
5. 捕获按 1 倍速进行，进度条走片长。请保持标签在前台；关掉或休眠会停。
6. 完成后浏览器下载 `presentation-4k.mp4`（或对应分辨率）。请允许本页下载文件。

编码走 Chrome / Edge 的标签页捕获 + WebCodecs（H.264 + AAC，优先硬件编码器）。Safari 或过旧浏览器会提示换 Chromium。5 分钟片子大约 5 分钟导完。

导出时舞台控件、角标、起播蒙层都隐藏。画面跟口播时钟 1 倍速播放，音轨是导入的 master WAV，不依赖系统回环。

三条预览路径，按手上有什么音频选：

| 场景 | 路径 |
|---|---|
| 真人口播或 voice-clone-tts 的完整配音 + SRT（主路径） | 导入后走 VO-First，`?auto=1` 播整段声音、按同一时间轴推进，导出或录制后核对起点 |
| 旧项目逐 step TTS | `?auto=1` 每步播 mp3 自动推进 → 一镜到底 |
| 无音频 | Manual 手动点击推进；页面导出此时无声，或后期任意剪辑工具配音 |

## 模式速查

| URL / 按键 | 行为 |
|---|---|
| 直接打开 | Manual：点击 / ←→ 推进，不播音频 |
| `?audio=1` 或按 `M` 切换 | Audio：进 step 播该步音频，手动推进（预览用） |
| `?auto=1` | Auto：整段时间轴（VO-First）或逐段 mp3（TTS）自动播 + 自动翻页 |
| `?auto=1&part=<id>` | 只播 plan.md `parts` 里该区间（VO-First 补拍 / 分段录制） |
| `?mute=1` | **静音**播放 —— 音频照常解码、`currentTime` 照常推进、`ended` 照常触发，翻页行为与有声时逐帧一致，只是听不见。**给 agent 自动化验证用**（`?auto=1&mute=1`），起播蒙层会显示「静音验证」。**录制时必须去掉** |
| Auto 下首次 `Space` | 起播（浏览器要用户手势）。**只起播不翻页** —— 模板已守卫 |

`?review=1&t=<绝对秒>` 只用于采样动画验帧，正式录制必须去掉 review/t 参数。

## VO-First：页面导出后的后期装配

导出文件已含画面 + 原声。仍要叠头像、插入整屏实拍、或多 part 拼接时，用导出的 MP4 当主轨：

- 叠头像：口播视频抠像（如 Screen Studio）→ 圆形贴 `AVATAR_CORNER` 角。头像与网页音频同源时共享时间基准
- 整屏实测视频步的 ~0.5s 短闪点 = 剪辑切点，把实测录屏（各带原声）切进去
- **多区间**：导出弹窗按 part 各导一段，后期按 plan.md 各区间的**绝对起止秒**拼接 —— 不用另算偏移

## 备选：录屏软件

打开 `?auto=1`（多区间时 `?auto=1&part=a`），在录屏软件中沿舞台角标框选 **16:9 内容矩形** → 开录 → 按 Space。Auto、Manual、Review 都保留外框；不要录入外边距、角标和控制条，也不要为录制把网页强制铺满窗口。
整段原声 seek 到区间起点连续播，画面跨过每个 step 的绝对起始秒自动翻页，
到区间 end 自动暂停、画面定住 —— 即可停录。

**为什么整段不切片**：切成 N 段 mp3 顺次播，段间有断点（听感割裂）、切割点不一定
在换气处、`ended → next → play` 每段几十 ms 延迟会累积漂移。整段 + 绝对时间戳 =
避免逐段播放的累计延迟；实际可见帧仍受浏览器调度、帧率和录制起点影响。机制详见模板 `src/hooks/useTimelineAuto.ts`。

录制保持页面可见并使用真实捕获会话。后台/隐藏浏览器可能降低 requestAnimationFrame 频率，即使音频时间还在推进；不能只看音频结束就判定动画流畅。实测抓取时同时检查 scene 时间与 audio.currentTime，并查看动作中帧。正式录屏后核对第一句与最后一句。

**后期装配**：
- 主轨 = 录出的网页画面 + 完整原声，画面以 SRT 和音频时钟推进；确认录屏工具捕获了系统音频，未捕获时用最终 WAV 配到经过核验的起播点
- 叠头像：口播视频抠像（如 Screen Studio）→ 圆形贴 `AVATAR_CORNER` 角。
  头像 mp4 与网页音频同源时共享时间基准；仍需核对录制起点、编码与设备偏移
- 整屏实测视频步的 ~0.5s 短闪点 = 剪辑切点，把实测录屏（各带原声）切进去
- **多区间补拍**：各 part 分别录（`?auto=1&part=a`、`?auto=1&part=b`…），后期按
  plan.md 各区间的**绝对起止秒**替换成片对应时段 —— 时间轴用的就是成片绝对秒，
  不用算偏移量，区间边界即切点

## TTS：Auto 一镜到底

前置：`public/audio/<id>/<N>.mp3` 全部就位（`npm run extract-narrations` →
`npm run synthesize-audio`，见 [`AUDIO.md`](AUDIO.md)）。

1. 打开 `?auto=1`，沿舞台外框选中 16:9 录制区，出现起播蒙层
2. 开录 → 按一次 Space → 逐步自动播 mp3 并推进 → 终态停住 → 停录，裁头尾即成品

> Auto 严格按音频结束推进（+200ms 缓冲），没有"等动画跑完"的兜底。看到动画被切 =
> 该步动画长于口播 → 调快动画 / 精简元素 / 拆 step（见 CRAFT.md 的动作节奏）。

## 录制就绪硬化清单（开录前逐项过）

1. **回到起点**：游标存 localStorage。按 `Home`（Mac：`fn + ←`）或数字 `1` 回开头，
   肉眼确认画面在第一页；VO-First 分区间录时确认蒙层显示的起止秒是想录的区间
2. **框选舞台**：外边距用于区分录制区，默认保留。画面是 `.stage-frame` 的直角 16:9 矩形，角标在外。窗口可为 16:10 或其他比例；只捕获矩形内容，不捕获整个浏览器窗口。切换模式后矩形尺寸应一致
3. **控件不入镜**：进度条 / 模式按钮悬停才出现 —— 开录后鼠标移到角落或移出屏幕别动
4. **Space 只起播不跳步**：模板守卫「`.auto-gate` 在屏时 Space 不翻页」，
   但仍要试录确认开场第一句在（丢 step 0 = 白录一整条）
5. **试录 10 秒**回放确认：① 第一句在 ② 无黑边裁歪 ③ 无按钮入镜 ④ 声画合拍。OK 再正式录
6. 记下整屏视频步闪点的大概时间，后期接实测视频
7. 修改前保存可回退版本（已有 Git 用现有工作流，否则保留备份），不覆盖原素材

## 录屏与后期工具

| 用途 | 工具 |
|---|---|
| macOS 录屏 | Cmd+Shift+5 选浏览器窗口 / QuickTime / Screen Studio（可同录头像 + 抠像） |
| 跨平台录屏 | OBS：窗口捕获，Canvas 1920×1080 60fps |
| 无音频路径后期 | DaVinci Resolve（免费）/ iMovie / 剪映（B 站抖音风字幕） |

导出 MP4 后另查实际编码帧：浏览器里的 audio/scene 时钟一致，不代表 CDP 捕获时间戳与成片 PTS 已对齐。排除起播蒙层，比较几个可见动作/时钟与输出时间；若实测存在固定录制偏移，补偿录制帧并重查，保留原音频和编辑时间轴，不凭经验一律套用某个补偿毫秒数。
