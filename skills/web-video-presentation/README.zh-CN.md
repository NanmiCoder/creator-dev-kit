# 网页视频演示

将最终音频与 SRT 变成可自动播放的 16:9 网页演示。连续场景、卡片变化和 MG 由同一声音时钟驱动；支持精确验帧。

从 [SKILL.md](SKILL.md) 开始，完整安装与双技能工作流见 [Creator Pipeline](https://github.com/NanmiCoder/creator-pipeline)。

产出是网页演示，`.pptx` 不在当前范围。审核后可在预览页右上角点 **导出**，选择 1K / 2K / 4K 下载 MP4；录屏软件作为备选。基于 ConardLi/garden-skills 的 MIT 版本继续改进，保留上游许可与来源。
