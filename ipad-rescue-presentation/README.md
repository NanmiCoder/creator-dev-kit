# iPad 复活记 — 互动演示网站

配合视频「吃灰两年的 iPad 被一只龙虾救活了」的演示幻灯片，基于 React + Framer Motion + Tailwind CSS 构建。

## 内容

7 页互动演示，讲述如何用 OpenClaw 龙虾 + WPS for Pad 构建移动端内容创作工作流，让吃灰的 iPad 重新进入生产力工作流。

| 页码 | 内容 |
|-----|------|
| 1 | Hook：靠一只 OpenClaw 龙虾救活 iPad |
| 2 | 以前为什么 iPad 总吃灰 |
| 3 | 工作流变了——OpenClaw 龙虾 |
| 4 | AI 初稿不能直接用 |
| 5 | WPS for Pad 接住工作流 |
| 6 | 实操演示占位 |
| 7 | 收尾金句 |

## 运行

```bash
npm install && npm run dev
```

## 技术栈

- React 18 + Vite 6
- Framer Motion（页面动画）
- Tailwind CSS（样式）
- Lucide React（图标）
